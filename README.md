# 淀粉粒考古图版库 · Starch Atlas

**正式网站：[ancientstarch.cn](https://ancientstarch.cn/)** · [致谢](https://ancientstarch.cn/credits)

淀粉粒考古图版库汇集植物微体遗存研究中的图版、文献与遗址资料，面向植物考古研究、教学和学术交流。v1.0 收录 628 幅图版、302 条文献记录，提供中英文图注、高清原图和文献出处。

## 浏览与检索

- **遗址探索**：在地图上选择遗址，查看相关文献和图版；点位标明原论文坐标或近似位置。
- **图版档案**：按植物、遗址、作者、年代和材料类型检索，查看分图释读、正文依据与高清图像。
- **文献目录**：查看中英文题名、作者、期刊与 DOI，从文献进入对应图版。
- **滚动致谢**：浏览文献作者、学术顾问、建设人员及机构与项目支持名单。

网站适配电脑与手机，支持中英文切换、图版缩放和并排比较。

## 使用与引用

使用范围为学术研究、教学及非营利性学术交流。文献、图像及相关资料的著作权归原作者或相应权利人所有。引用图像或研究结论时，请标注对应的原始文献。

引用资料库可采用：

> 淀粉粒考古图版库（Starch Atlas）[DB/OL]. v1.0, 2026-11-05. https://ancientstarch.cn/.

数据勘误与联系：[2021119053@stumail.nwu.edu.cn](mailto:2021119053@stumail.nwu.edu.cn)。提交勘误时，请附文献题名或图版编号。

## 仓库结构

| 路径 | 内容 |
| --- | --- |
| `website/` | 正式网站前端、图版目录、研究索引与预览图 |
| `media-manifest.json` | 高清原图的文件名、大小与 SHA-256 |
| `scripts/` | 资源完整性与发布检查 |
| `r2-worker/` | 可选的静态资源与原图服务 |
| `.github/workflows/` | GitHub Pages 发布流程 |
| `docs/DEVELOPMENT.md` | 本地预览、验证和部署说明 |

正式网站采用国内托管与 CDN 分发。高清原图通过网站的 `/media/` 路径提供。
